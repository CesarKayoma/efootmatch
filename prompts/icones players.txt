Crie um script em Python completo, modular e bem comentado para baixar fotos de jogadores de futebol, transformá-las em avatares quadrados leves para um site e salvá-las localmente.

### ENTRADA DE DADOS
- O script deve ler uma lista de nomes de jogadores a partir de um arquivo chamado `jogadores.txt` (um nome por linha) no mesmo diretório.

### REQUISITOS TÉCNICOS E FLUXO
1. **Fonte de Busca:** Utilize a API pública da Wikipedia (MediaWiki API) ou Wikimedia Commons para buscar a imagem principal de cada jogador, evitando raspagem direta do Google Imagens para não sofrer bloqueios. Inclua um `User-Agent` personalizado nos cabeçalhos HTTP.
2. **Download Seguro:** Use a biblioteca `requests` com timeout de 10 segundos e tratamento de exceções (`try/except`) para que o script não pare caso um jogador não seja encontrado ou ocorra erro de rede. Adicione uma pausa (`time.sleep(1)`) entre as requisições.
3. **Processamento de Imagem (Pillow):**
   - Converta a imagem para o modo `RGB` (caso seja PNG com transparência ou outro formato).
   - Faça um corte centralizado (center crop) na proporção exata de **1:1 (quadrado)** sem distorcer o rosto.
   - Redimensione a imagem para **150x150 pixels** usando interpolação de alta qualidade (`Image.Resampling.LANCZOS`).
4. **Salvamento e Padronização:**
   - Crie automaticamente uma pasta chamada `avatares_jogadores` caso ela não exista (use `pathlib`).
   - Salve as imagens no formato **.webp** (qualidade 85) para garantir carregamento rápido na web.
   - Padronize o nome do arquivo em formato *slug* (letras minúsculas, sem acentos, espaços substituídos por hífen. Ex: "Vini Jr" -> `vini-jr.webp`).
5. **Relatório Final:** Ao terminar, exiba no terminal um resumo com o total de imagens baixadas com sucesso e gere um arquivo `nao_encontrados.txt` listando os jogadores cujas fotos falharam.

### SAÍDA ESPERADA
- Forneça primeiro o comando `pip install` com todas as bibliotecas necessárias.
- Entregue o código Python completo e pronto para executar, sem trechos omitidos ou placeholders.
